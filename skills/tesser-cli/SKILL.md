---
name: tesser-cli
description: Run dev servers, tests, typechecks, and builds on persistent cloud boxes while the code stays local. Use when the user wants a dev server running off the laptop with localhost as the window into it, several worktrees running at once, a box for tests or heavy commands, or when the repo has service manifests in .claude/skills/tesser/*.toml.
---

tesser explains itself. Before your first command:

    tesser --help          how it works, and the rules
    tesser <cmd> --help    what that command actually does

Errors name the next command to run. Trust them over anything you remember.
